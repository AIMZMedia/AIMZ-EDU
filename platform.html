FAQ자주 묻는 질문

도입 전 우려하실 부분과,
준비된 대응입니다

Q1제공사가 단가나 정책을 바꾸면?
여러 제공사의 AI를 함께 쓰는 구조라 특정 제공사에 기대지 않습니다. 크레딧 단가는 학기 단위 조정 조항으로 계약에 적어 둡니다.
Q2수업 중 API 한도가 넘으면?
API 키 여러 개를 묶은 키 풀(pool)이 한도에 닿으면 자동으로 다음 키로 전환합니다. 상태도 계속 지켜보므로 수업 중에 서비스가 멈추지 않습니다.
Q3학생이 유해 콘텐츠를 만들면?
제공사 안전 정책과 자체 모더레이션으로 두 번 막습니다. 모든 생성 기록을 로그로 보존해 나중에 추적할 수 있습니다.
Q4개인정보가 새지 않을까요?
필요한 정보만 받습니다. 비밀번호는 PBKDF2-SHA256으로 60만 회 반복 해싱해 보관하고, 모든 통신은 HTTPS로 암호화합니다. 학교마다 데이터 공간(테넌트)이 나뉘어 자료가 섞이지 않습니다.
Q5내년 예산이 줄어들면?
RISE, AID 등 여러 재정지원사업과 연계해 재원을 나눕니다. 크레딧 규모는 예산에 맞춰 조정합니다.
Q6도입까지 얼마나 걸리나요?
클라우드 구축은 1주면 됩니다. 학기 시작 4주 전에 계약하면 그 학기에 바로 씁니다. 보안 요건에 따라 기관 서버에 설치하는 온프레미스 구축도 고를 수 있습니다.
