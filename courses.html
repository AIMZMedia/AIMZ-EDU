01기초 · AI 콘텐츠 기초과정

AI 콘텐츠 제작의
전 과정을 한 번에

생성형 AI로 콘텐츠 한 편을 처음부터 끝까지 직접 만들며 제작 흐름 전체와 기본기를 익힙니다. 이미지 · 영상 · 사운드가 하나로 이어지기 때문에, 전 과정을 직접 거쳐야 새로운 도구에도 응용할 수 있습니다.

교육 대상
AI 입문자
실습 환경
강의 장소 · 노트북
산출물
AI 콘텐츠 1편

수업 구성

8개 모듈 모두 필수

  1. 01생성형 AI 콘텐츠 이해변화와 현재, 모델 종류와 용도
  2. 02LLM 활용 기초ChatGPT · Claude 기획 보조, 프롬프트
  3. 03레퍼런스 리서치참고 자료 탐색, 스타일 · 무드 구성
  4. 04기획 · 스토리보드아이디어 정리, 장면 분할
  5. 05이미지 생성키 이미지 · 캐릭터 시트 · 일관성
  6. 06영상 생성이미지 → 영상, 카메라 무빙
  7. 07사운드 생성음성 · 배경음악 · 효과음(SFX)
  8. 08편집 · 완성컷 연결 · 자막 · 믹싱, 발표와 피드백

장르 선택

하나를 고릅니다. 수업 흐름은 같고, 장르에 맞춰 예제와 제작 팁이 달라집니다.

GENRE 1

광고

브랜드 · 제품 숏폼 광고 한 편 완성

GENRE 2

애니메이션

캐릭터 일관성 중심의 짧은 애니메이션

GENRE 3

영화

실사 톤 시네마틱 트레일러 컷

기대 효과

  • 직접 완성한 AI 콘텐츠 1편
  • 기획부터 편집까지 AI 제작 흐름 이해
  • 업무에 바로 쓰는 LLM · 프롬프트 기본기
  • 목적에 맞는 AI 도구를 고르는 판단력

02심화 · AI 콘텐츠 심화과정

바이브코딩으로
제작 효율화와 품질 고도화

코드를 몰라도 LLM과 대화하며 제작에 필요한 프로그램을 직접 만들고, 반복 작업을 줄이거나 결과물 품질을 끌어올립니다. 정해진 도구를 배우는 대신 도구를 만드는 방법을 익혀, 교육이 끝난 뒤에도 새 업무에 바로 적용합니다.

교육 대상
기초 이수자 · AI 제작 경험자
사용 도구
Claude Code · ChatGPT
실습 환경
강의 장소 · 노트북
산출물
바이브코딩 이해 · 효율화 제작 도구

수업 구성

공통 필수 · 바이브코딩

  1. 01바이브코딩의 이해LLM에게 말로 설명해 코드를 만드는 원리와 한계
  2. 02효율화 포인트 찾기반복 · 수작업 구간을 정의하는 방법
  3. 03도구 제작 · 검증만들고, 실행하고, 오류를 고치는 흐름
  4. 04배포 · 공유팀이 함께 쓰는 형태로 정리하고 배포

적용 모듈

기관 업무에 맞춰 조합합니다. 주제를 제안하셔도 됩니다.

MODULE A

반복 작업 자동화

파일 정리, 리사이징, 대본 → 콘티 변환 등 반복 업무 도구 제작

MODULE B

화질 고도화

납품 기준에 맞춘 업스케일 · 화질 보정 파이프라인 구성

MODULE C

코드 기반 모션그래픽

자막 · 인포그래픽 · 타이틀 모션을 LLM 코드로 자동 생성

수업 사례

수업에서 직접 만든 제작 자동화 도구

CASE스토리보드 자동화 툴

개발 경험 없는 인력이
직접 만들어 팀에서 씁니다

기획 · 제작 · 행정 인력이 실제로 동작하는 도구를 만들어 팀 업무에 바로 사용했습니다.

  • 산출물 — 스토리보드 생성기 · 이미지 · 영상 생성 스튜디오
  • Claude · Cursor 등으로 요구사항을 대화로 구체화
  • 문법 암기가 아닌 문제 정의와 검증 — 비개발 인력도 완주

03전문 · AI 콘텐츠 전문과정

ComfyUI 중심
사내 AI 전문 인력 양성

생성형 AI는 하루, 일주일, 한 달 단위로 바뀝니다. 외부 플랫폼에만 기대지 않고 변화를 직접 따라가며 사내 시스템을 구축 · 운영할 인력을 키웁니다. 핵심은 생성 과정을 직접 설계하는 오픈소스 도구 ComfyUI입니다.

교육 대상
사내 전문 인력 양성 기관
실습 환경
원격 ComfyUI · 고사양 PC 불필요
산출물
ComfyUI 이해 · 자체 운영 역량

수업 구성

공통 필수 · ComfyUI

  1. 01ComfyUI 기초노드 워크플로우 구조, 이미지 생성, 파라미터 제어
  2. 02영상 워크플로우이미지 → 영상, 최신 오픈소스 영상 모델 적용
  3. 03비용 산정 · 구축 설계모델별 단가 · GPU 비용, 사내 구축 환경 설계
  4. 04워크플로우 템플릿팀 공통 제작 방식을 템플릿으로 정리 · 공유

고도화 모듈

전문과정 1은 필수, 2 · 3은 선택하거나 제안할 수 있습니다.

전문과정 1필수

ComfyUI

노드 워크플로우 설계와 원격 GPU 실행 — 모든 전문과정의 공통 기반

전문과정 2선택

Blender × 3D AI

카메라 · 구도를 3D로 정밀하게 통제하고 AI로 실사화

전문과정 3선택

AI VFX

인물 교체 · 합성 등 완성 영상의 특수 효과 처리

기대 효과

  • 팀 전용 ComfyUI 워크플로우 템플릿
  • AI 변화를 직접 따라가는 사내 전문 역량
  • 직원들이 사내 제작 환경을 직접 구축 · 운영하는 힘
